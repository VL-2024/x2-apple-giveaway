# X2 LOTO Apple Giveaway Landing

Одностраничный лендинг для отдельного домена под розыгрыш призов от Apple.

## Что внутри

- `index.html` — готовая HTML-страница со встроенными стилями и небольшим JS.
- Ссылки уже прописаны:
  - регистрация: `https://x2.kg/?from=apple`
  - Instagram: `https://www.instagram.com/x2loto.kg`

## Как запустить через GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В блоке **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
4. Нажмите **Save**.

После включения GitHub Pages сайт будет доступен примерно по адресу:

`https://vl-2024.github.io/x2-apple-giveaway/`

## Подключение отдельного домена

Когда будет выбран домен, нужно:

1. В настройках GitHub Pages указать домен в поле **Custom domain**.
2. Добавить DNS-записи у регистратора домена.
3. Добавить в репозиторий файл `CNAME` с доменом.
